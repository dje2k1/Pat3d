Local patch (three.webgpu.js): GPUTextureViewDescriptor.swizzle default 'rgba' -> undefined.
Chromium <= 14x types GPUTextureViewDescriptor.swizzle as a dictionary and rejects the string 'rgba'
("The provided value is not of type 'GPUTextureComponentSwizzle'"), which broke every render pass on WebGPU.
Leaving it undefined means the identity swizzle on every browser. Re-apply after an upgrade:
  sed -i 's/swizzle="rgba"/swizzle=void 0/g' lib/three/three.webgpu.js
